# Legacy Harbour-CUI sources

Previous standalone CUI helpers from this repository before the
[tfonrouge/HBTui](https://github.com/tfonrouge/HBTui)-based framework was adopted:

- `win.prg` — SaveScreen/RestScreen window class
- `cui.ch` — Application / GetList macros
- `samples/` — earlier CUI demos

Kept for reference only; the active library lives in `src/` and builds via `hbtui.hbp`.
